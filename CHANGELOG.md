# Changelog

## 0.1.6

- исправлена читаемость последних столбцов таблиц «Файлы» и «Папки»: включены предсказуемые режимы ширины и горизонтальная прокрутка;
- полный путь выбранного файла и папки теперь всегда показывается отдельным полем под таблицей без обрезания;
- добавлена кнопка «Копировать путь»;
- для имени и столбца пути добавлены tooltip-подсказки с полным путём;
- стартовый размер окна увеличен до 1360×820, минимальный — 1040×680.

## 0.1.5

- на вкладке «Обзор» можно выбрать любую дополнительную локальную папку через системный диалог Windows;
- выбранные папки сохраняются между запусками в локальных настройках и участвуют в следующих сканированиях;
- дополнительную папку можно убрать из списка; после следующего сканирования её старые записи перестают считаться актуальными;
- корень любой выбранной зоны защищён от удаления так же, как Рабочий стол и Загрузки;
- пересекающиеся корни автоматически схлопываются, чтобы одна и та же папка не сканировалась дважды с разной глубиной;
- добавлен регрессионный тест на произвольные и пересекающиеся корни сканирования.

## 0.1.4

- во вкладке «Файлы» добавлены кнопки «Выделить все показанные» и «Снять выделение»;
- массовое выделение работает по текущему фильтру: можно сначала отфильтровать папку/формат/категорию/решение, затем выделить все видимые строки;
- добавлен счётчик «Выбрано: N из M»;
- для ручного выбора диапазона оставлена стандартная схема Windows: Shift — диапазон, Ctrl — отдельные строки, Ctrl+A — все строки таблицы.

## 0.1.3

- исправлен запуск поверх базы 0.1.1: индекс папок теперь создаётся только после миграции схемы;
- добавлено решение для файлов «В C:\Загрузки» с защитой от перезаписи одноимённых файлов;
- добавлен `Musorka.vbs` для запуска без окна командной строки после однократной установки зависимостей;
- добавлена инфраструктура будущего значка: `assets\musorka.ico` автоматически используется окном, панелью задач и PyInstaller-сборкой, если файл существует; сам значок в эту версию не добавлен.

## 0.1.2

- массовое удаление вложенных папок через общий «План уборки»;
- для папок доступны «В корзину» и «Удалить навсегда»;
- корни Рабочего стола и Загрузок защищены от удаления;
- fail-closed проверка содержимого папки перед выполнением: если число файлов или суммарный размер изменились после сканирования, действие отменяется;
- папка не ставится на удаление, если внутри есть файлы со статусом «Оставить», «Потом» или «В Google Drive»;
- вложенные выбранные папки схлопываются в одну родительскую операцию, чтобы дерево не удалялось дважды;
- вкладка «Программы» получила «Удалить программу» и «Открыть папку установки»;
- удаление программы запускает штатный UninstallString Windows, а для MSI `/I{...}` нормализуется в `/X{...}`;
- добавлено чтение QuietUninstallString в реестр (для диагностики; автоматическое тихое удаление не используется);
- журнал фиксирует запуск/ошибку деинсталлятора;
- схема SQLite мигрируется поверх базы 0.1.1 без сброса решений;
- 8/8 regression tests.

## 0.1.1

- сканирование папок Рабочего стола и Загрузок как отдельного реестра;
- отдельная вкладка «Папки» с рекурсивным числом файлов, размером и полным путём;
- переход из папки прямо к её файлам;
- фильтр файлов по конкретному расширению (`.csv`, `.xlsx`, `.pdf` и т. д.), а не только по категории;
- фильтр файлов по выбранной локальной папке;
- вкладка Google Drive получила кнопки на Google Cloud Console и официальную инструкцию;
- добавлены регрессионные тесты на рекурсивные папки и фильтры формата/папки.

## 0.1.0

Первый MVP:

- скан Рабочего стола и Загрузок;
- категории и дубли;
- массовые решения «Оставить / В Google Drive / В корзину / Удалить навсегда / Потом»;
- отдельный реестр «Потом» с полным путём и заметкой;
- staged plan перед разрушительными действиями;
- Google Drive folder browser + создание папок + проверяемая загрузка;
- Windows Registry inventory программ и экспорт списка для переноса;
- журнал действий;
- Windows runner и PyInstaller build script.
